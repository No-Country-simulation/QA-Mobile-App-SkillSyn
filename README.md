# App Móvil: Gestión de Servicios - QA Manual

Este proyecto consiste en el testing integral de una aplicación móvil diseñada para la gestión de servicios. Mi rol se centró en asegurar una experiencia de usuario fluida y libre de errores críticos en entornos Android e iOS.

### 🛠️ Herramientas y Entornos:
* **Dispositivos**: Pruebas en dispositivos reales y emuladores.
* **Gestión de Defectos**: Documentación y seguimiento de bugs en Trello/Jira.
* **Proxy/Debugging**: Uso de herramientas de inspección para validación de API.
* **Documentación**: Diseño de casos de prueba específicos para mobile (gestos, conectividad, batería).

### 📋 Tareas de QA Realizadas:
* **Pruebas de Usabilidad (UX)**: Validación de la interfaz táctil, gestos (swipe, tap) y adaptabilidad de pantallas (Responsive Mobile).
* **Testing de Conectividad**: Verificación del comportamiento de la app ante cambios de red (Wi-Fi a 4G/5G) y modo offline.
* **Validación de Notificaciones Push**: Pruebas de recepción y flujo de usuario al interactuar con alertas en tiempo real.
* **Regression Testing**: Ejecución de ciclos de prueba tras cada actualización de la build para asegurar la estabilidad de las funciones core.
* **Exploratory Testing**: Sesiones de pruebas libres para identificar comportamientos inesperados fuera de los casos de uso estándar.
